# Smart Finance

Laravel 12 personal finance tracker for income, expenses, budgets, savings goals, recurring transactions, reports, notifications and account settings.

## Local setup (Windows/XAMPP)

1. Open Command Prompt in the project folder.
2. Install PHP dependencies:

```cmd
composer install
```

3. Create your environment file:

```cmd
copy .env.example .env
php artisan key:generate
```

4. Make sure `.env` uses SQLite. Create the database file if needed:

```cmd
if not exist database\database.sqlite type nul > database\database.sqlite
```

5. Build frontend assets:

```cmd
npm install
npm run build
```

6. Prepare the database:

```cmd
php artisan migrate:fresh --seed
php artisan storage:link
```

If `storage:link` says the link already exists, that is harmless.

7. Start Laravel:

```cmd
php artisan serve
```

Open `http://127.0.0.1:8000`.

## Seed account

The seeder creates:
- Email: `test@example.com`
- Name: `Test User`

Use the password generated by the Laravel UserFactory in your local copy, or register a new account from `/register` after removing the seeded account if preferred.

## Main modules

Dashboard, unified Transactions, Income, Expenses with receipt upload, Categories, Income Sources, Payment Methods, Budgets, Savings Goals, Recurring Transactions, Reports/CSV export, Notifications, Activity Logs, Profile and Settings.

## Important

Do not commit `.env`, real credentials, uploaded receipts, or the `vendor`/`node_modules` directories to source control.
